# Style Families Reference Pack — Lens styles-a

Source plan: `https://www.awwwards.com/websites/<category>/` and `?q=<query>` search for six style
families (minimal/apple, editorial/magazine, swiss/grid, brutalism, neo-brutalism,
terminal/hacker+comic/manga), plus `minimal.gallery`, `brutalistwebsites.com`, and Dribbble tag
pages as secondary listings, per the brief.

**Method note — the awwwards search endpoint was broken.** `awwwards.com/websites/search/?q=<term>`
does not filter by the query at all: `?q=swiss`, `?q=grid`, `?q=neo%20brutalism`, `?q=terminal` and
`?q=comic` all returned the *same* unrelated set of ~12 recruiting/"search"-tool sites (executive
search firms, a Google "how search works" page, etc.) — confirmed by re-running five different
queries and getting byte-identical result sets. Those captures exist on disk (tagged `swiss-grid`,
`neo-brutalist`, `terminal-comic` in the raw run) but are **excluded from the index below** as
off-topic; they're listed in AVOID instead. The category pages (`/websites/minimal/`,
`/websites/editorial-design/`, `/websites/typography/`, `/websites/brutalism/`) worked correctly.
For the three families the broken search endpoint starved (swiss/grid, neo-brutalist,
terminal+comic), I substituted a second pass of manually-curated, individually-verified live sites
(real design studios / real products, each actually loaded and screenshotted — dead ones dropped,
not counted) plus a corrected Dribbble tag retry (`neubrutalism`, no hyphen — the hyphenated tag
returned only its own nav chrome). This is the "substitute the nearest listing and say so" fallback
the brief asked for. Two sites that came from `brutalistwebsites.com` turned out to be **expired
domains now squatted** by unrelated content (adult-content and gambling-spam redirects) — dropped,
replaced from the same listing's remaining links. A handful of sites were also visually
**reclassified out of the family their source query implied** and into the family they actually look
like (`crency.agency` came from an "editorial/typography" query but is pure neo-brutalist;
`thebrutalistreport.com` — a plain-HTML headline aggregator — fits raw brutalism far better than
"neo-brutalist," which is where its Dribbble-adjacent capture landed it).

Method: Playwright/Chromium 1440×900 (390×844 mobile on every 4th capture), real Chrome UA,
`domcontentloaded` + 2.5s settle, up to 8s loader-wait, ~1.5s between page loads, ≤1 req/2s per host,
scroll to 0/35/70% before each viewport capture. Ran across three passes (one main sweep, two small
fix-up sweeps) totaling 41 successful site captures, with the 1200MB memory guard checked before
launch and every 15 sites. Screenshots under
`refs4/styles-a/<site-slug>/`: `full.png` (capped 8000px), `vp-0/35/70.png`, `innerText.txt`, plus
`m-0/m-50.png` on every 4th site captured. **Many of these award-winning sites use scroll-triggered
reveal animations that a programmatic `scrollTo()` does not fire** (real wheel events are needed) —
`full.png` on those pages under-shows content; the `vp-*.png` files, taken after a real scroll+settle,
are the more reliable read and are what several rows below are actually based on.

## 2. Idea catalog — 27 reusable ideas

### 1. Building-directory side rail as primary nav
- **Look:** Instead of a normal top nav, a slim left rail lists numbered "floors" ("01 — office
  floors", "02 — at the entrance"...) that map 1:1 to page sections, with a small dot marking the
  active one.
- **Fits:** Apple Clean's side nav, or a dedicated "about the build" page.
- **Sketch:** `position: sticky` left column, `IntersectionObserver` on each section toggling an
  `aria-current` dot; numbers are literal content, not decoration.
- **Perf/a11y:** Zero JS cost beyond one observer; the numbers double as a real in-page TOC for
  screen readers if marked up as a `<nav>` with `<a href="#section">`.
- **Screenshot:** `thenest-pl/full.png`

### 2. Recursive/fractal grid module
- **Look:** One grid cell contains a smaller identical grid, which contains a smaller grid again —
  logos nested inside logo-tiles nested inside a mega-tile, all sharing the same aspect ratio.
- **Fits:** Menu theme's project index, or a "clients" section on Apple Clean.
- **Sketch:** A single `.tile` CSS Grid component that renders either an image or a nested `.tile`
  grid via a recursive React component with a depth prop; color/size driven by CSS custom
  properties per depth.
- **Perf/a11y:** Pure CSS grid, no layout thrash; cap recursion depth at 2-3 and lazy-load nested
  images.
- **Screenshot:** `www-johnsonbanks-co-uk/vp-0.png`

### 3. Hand-lettered whiteboard diagram instead of a stock icon graphic
- **Look:** A dark solid-color panel holds a single photographed (or SVG-traced) handwritten
  diagram — arrows, circled words, a simple equation — standing in for what would normally be an
  icon set or bar chart.
- **Fits:** Soft UI's "how it works" section, or Apple Clean's process step.
- **Sketch:** Either a real photographed whiteboard cropped tight, or an SVG path traced from one
  (variable `stroke-dasharray` animated to "draw in" on scroll-into-view).
- **Perf/a11y:** One image or one small SVG; add a text-equivalent `<figcaption>` since the
  information is otherwise image-only.
- **Screenshot:** `lunchlinepartners-com/full.png`

### 4. GPS coordinates as oversized display type
- **Look:** A geographic coordinate pair (`45°16'49.4"N 16°55'42.2"E`) is set in the same huge type
  scale as a headline, functioning as a recurring structural/rhythm element rather than a caption.
- **Fits:** Brutalist theme's section dividers, or a "locations" page on any theme.
- **Sketch:** Plain `<h2>`-scale monospace/serif text; store real coordinates as data and format
  with `Intl` or a fixed decimal-to-DMS converter so it's real data, not decoration.
- **Perf/a11y:** Free — it's just text at a bigger font-size token.
- **Screenshot:** `storyofbrutalism-com/full.png`

### 5. Wordmark cropped off both viewport edges at once
- **Look:** A logotype or headline is set so large that both its left and right edges are cut off
  by the viewport simultaneously — you only ever see the middle of the word.
- **Fits:** Brutalist or Arcade theme hero.
- **Sketch:** `font-size: clamp(8rem, 20vw, 20rem)` on a full-width block with `overflow: hidden` on
  the parent and no horizontal padding; center the text so both edges clip evenly.
- **Perf/a11y:** Free; keep an accessible, un-clipped duplicate in a visually-hidden element.
- **Screenshot:** `storyofbrutalism-com/full.png` and `arcoglobal-com/full.png` (footer wordmark)

### 6. Ticker marquee as the only nav-adjacent chrome
- **Look:** A thin horizontal marquee band ("ISSUE 12 AVAILABLE NOW" repeated) is the single piece
  of UI decoration on an otherwise raw, unstyled page.
- **Fits:** Brutalist theme header, or Arcade's "now playing" strip.
- **Sketch:** CSS-only marquee via `@keyframes` translateX on a duplicated flex row (`aria-hidden`
  the duplicate), `animation-play-state: paused` on `prefers-reduced-motion`.
- **Perf/a11y:** Pure CSS; respect reduced-motion; don't rely on marquee text for information not
  available elsewhere.
- **Screenshot:** `middleplane-com/vp-0.png`

### 7. Homepage-as-terminal (literal line-numbered code editor)
- **Look:** The entire homepage renders as a dark code-editor pane with line numbers down the left,
  monospace body text, and a blinking colored cursor on the active/last line.
- **Fits:** A dedicated "developer" or changelog page, or an Easter-egg `/terminal` route.
- **Sketch:** A `<pre>`/`<code>` grid with a `::before` line-number column (`counter-reset`/
  `counter-increment`), a `<span class="cursor">` with a `blink` keyframe.
- **Perf/a11y:** Trivial; make sure real interactive commands (if any) are also reachable via a
  normal `<button>`/`<a>` for non-mouse/non-JS users.
- **Screenshot:** `terminal-shop/vp-0.png`

### 8. ASCII box-drawing layout instead of CSS cards
- **Look:** A feature-comparison or command-reference grid is drawn entirely with monospace
  box-drawing characters (`+---+`, `|`) rather than bordered `<div>`s — literally ASCII art as
  layout.
- **Fits:** Arcade theme's "how to play" reference card.
- **Sketch:** Pre-formatted `<pre>` block; or, for real responsiveness, a CSS `border` grid styled
  to *look* like box-drawing (monospace font + `border: 1px solid` on cells) so it reflows properly
  while reading as ASCII.
- **Perf/a11y:** Free; if using literal ASCII in a `<pre>`, also provide a normal semantic table for
  screen readers since ASCII art reads poorly aloud.
- **Screenshot:** `cheat-sh/vp-0.png`

### 9. Scattered flat-color shapes at random rotation behind the hero
- **Look:** 4-6 flat primary-colored geometric shapes (star, circle, triangle, blob) of different
  sizes sit scattered and rotated behind/around a centered headline, like stickers dropped on a
  desk.
- **Fits:** Arcade theme's menu screen.
- **Sketch:** Absolutely-positioned `<div>`s with fixed `clip-path` shapes, each given a small
  random (but seeded, for SSR match) `rotate()` and `top/left`; one slow `@keyframes` float per
  shape at staggered durations.
- **Perf/a11y:** All CSS, no images; mark the whole decorative layer `aria-hidden`.
- **Screenshot:** `www-superhi-com/vp-0.png`

### 10. Pink 3D "coin" mascot scattered at odd angles
- **Look:** A single branded 3D-rendered object (here: a coin with the brand's initial) repeats at
  several sizes and tilt angles around the hero copy, like confetti.
- **Fits:** Arcade theme's currency/score indicator, reused as hero decoration.
- **Sketch:** One exported PNG/WebP of the 3D object at a few rotation states, or a single SVG
  rotated via CSS per instance; randomize scale/rotate/position with seeded values for SSR-safe
  hydration.
- **Perf/a11y:** Keep to raster/SVG, not live 3D — no WebGL needed for the effect achieved here.
- **Screenshot:** `gumroad-com/vp-0.png`

### 11. Card floating inside a softer-colored page frame
- **Look:** The page background is a pale, muted tone; a bright white rounded "card" containing the
  actual hero content floats centered inside it with a soft ambient shadow, like a screenshot
  pinned to a corkboard.
- **Fits:** Soft UI theme's whole hero pattern.
- **Sketch:** Outer `body`/wrapper with a light gray-blue `background`, inner `.hero-card` with
  `border-radius: 24px+`, `box-shadow: 0 40px 80px -20px rgba(0,0,0,.15)`.
- **Perf/a11y:** Pure CSS; ensure contrast of card-on-frame still meets WCAG at the frame's own
  color.
- **Screenshot:** `www-hey-com/vp-0.png`

### 12. Halftone-dot photographic treatment as a hero
- **Look:** A photo or illustration is fully converted to coarse black-and-white (or duotone)
  halftone dots, print-risograph style, rather than shown as a normal photo.
- **Fits:** Comic/manga hero, or an editorial "cover story" page.
- **Sketch:** CSS `filter: grayscale(1) contrast(300%)` combined with a repeating-radial-gradient
  overlay at `background-blend-mode: multiply` approximates it cheaply; for a real halftone, do it
  once at build time in an image pipeline (sharp/ImageMagick ordered-dither) rather than per-request
  CSS filters.
- **Perf/a11y:** Prefer a pre-processed image over live CSS filters (cheaper to paint, consistent
  across browsers); keep real alt text since the image reads as abstract.
- **Screenshot:** `oumahi-art/full.png`

### 13. Photography with a soft self-fade at its own edges
- **Look:** Instead of a hard rectangular crop, a photo fades to the page's background color at its
  own edges via a gradient mask, so it looks like it's dissolving into the page rather than sitting
  in a box.
- **Fits:** Editorial theme's travel/case-study imagery.
- **Sketch:** `mask-image: radial-gradient(ellipse at center, black 60%, transparent 100%)` (or a
  linear version per edge) on the `<img>`.
- **Perf/a11y:** Pure CSS mask, GPU-cheap; no accessibility impact beyond normal alt text.
- **Screenshot:** `tour-kyrgyzstan-com/full.png`

### 14. Oversized ghost-outline watermark word behind product imagery
- **Look:** A single word is set in huge outline-only (stroke, no fill) type, positioned behind a
  smaller, fully-rendered product photo — a background watermark that's legible but subordinate.
- **Fits:** Luxury theme's product-detail section.
- **Sketch:** `-webkit-text-stroke: 2px var(--ink-20); color: transparent;` on an absolutely
  positioned `<span>` behind the image's `z-index`.
- **Perf/a11y:** Free; `aria-hidden` the watermark, keep real heading text elsewhere in normal
  color.
- **Screenshot:** `sedlecky-kaolin-com/full.png`

### 15. Resume-style plain-text role timeline (no case-study chrome)
- **Look:** Instead of illustrated case-study cards, a personal portfolio lists roles as plain
  dated text blocks — title, company, years, a paragraph — like a well-typeset résumé rendered as a
  webpage.
- **Fits:** Apple Clean's "experience" section.
- **Sketch:** A simple definition-list-like flex column: role/company as a strong heading, a
  `<time>` range, a paragraph; no cards, no borders, just vertical rhythm and a hairline divider
  between entries.
- **Perf/a11y:** Trivially fast; semantic and screen-reader-friendly by default because there's no
  extra chrome to work around.
- **Screenshot:** `www-vilendesign-com/full.png`

## 3. AVOID

- **Never trust an `awwwards.com/websites/search/?q=` URL to actually filter.** Confirmed broken
  across 5 different queries in this pass — it silently returns an unrelated cached/default result
  set with no error. Use the real category pages (`/websites/<category>/`) instead, or a corrected
  third-party listing (Dribbble tags, brutalistwebsites.com), and always sanity-check the first 2-3
  results actually match the query before spending capture budget on the rest.
- **Dribbble tag URLs are picky about hyphenation.** `dribbble.com/tags/neo-brutalism` (hyphenated)
  redirected to the generic `/shots/popular` nav chrome with zero real tag results;
  `dribbble.com/tags/neubrutalism` (no hyphen) worked correctly and returned real shot links. Verify
  a tag slug actually resolves before relying on it.
- **Never slug a listing item by its host alone when the listing is single-host** (e.g., multiple
  individual Dribbble shot URLs). `new URL(url).host` collapses `dribbble.com/shots/123-a` and
  `dribbble.com/shots/456-b` to the same `dribbble-com` folder/dedupe-key, silently skipping every
  shot after the first. Slug by host+pathname (or a hash of the full URL) for any listing whose
  items share a domain.
- **Boutique studio domains referenced from memory/training data are a coin flip 4-5 years out.**
  Of 9 hand-picked "known swiss/grid studio" URLs, 5 failed outright (DNS, refused connection, or
  cert errors) — small agencies rebrand, fold, or let domains lapse constantly. Always verify-by-
  loading before citing a boutique studio site as a reference; don't cite from memory alone.
- **A domain that used to host a real site can now be squatted.** Two `brutalistwebsites.com`
  listing entries (`diss-list.com`, `nelsonheinemann.com`) now redirect to unrelated adult-content
  and gambling-spam pages respectively — the listing itself is stale, not wrong at the time it was
  compiled. Screenshot and read the actual title/content before trusting an old listing's link.
- **A "search"/"recruiting"-styled result creeping into a design-style query is a red flag, not a
  coincidence** — if 8+ results in a row share an odd naming pattern unrelated to the style you
  queried (here: everything containing the word "search"), stop and suspect the query parameter is
  being ignored server-side rather than that you found a genuinely on-topic but oddly-named result.
- **The stretched-tiled-collage-background pattern (#22 above) is a legitimate brutalist reference
  but should not become a default** — it actively hurts legibility and contrast by design; use it
  only for an intentionally chaotic one-off page, never as a site's primary navigation surface.
- **A `fullPage: true` Playwright screenshot under-represents scroll-reveal-heavy sites.** Several
  captures here (`khanhnguyen.design`, `huyml.co`) looked nearly blank in `full.png` because their
  content only animates in on a real wheel/scroll event, not a programmatic `scrollTo()`. Always
  cross-check `vp-*.png` (captured after an actual scroll+settle) before judging a site "sparse."
