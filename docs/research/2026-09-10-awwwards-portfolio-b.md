## 2. Idea catalog (30 entries)

### 1. Loading-state-as-hero (spec-chip preloader)
**Looks like:** Centered giant serif wordmark on black; small bracketed capability tags (`[ ]EDITING`, `(VFX)`, `SOUND`) float around it; a thin progress bar plus a `NNN/100` counter bottom-right ticks up while assets stream.
**Fits:** New "loading" treatment for maxfolio's Arcade or Apple Clean hero; or a one-time first-visit splash before the typographic hero.
**Sketch:** framer-motion `useState` counter driven by a real asset-loading promise (not faked past ~800ms), tags as `position:absolute` chips with `whileInView`/stagger fade-in.
**Perf/a11y:** Never block > 1.5s on a fast connection; add `aria-live="polite"` on the counter; respect `prefers-reduced-motion` (skip chip float).
**Ref:** `refs4/awwwards-portfolio-b/forms-world/vp-0.png`

### 2. 3D-asset ghost-silhouette preloader
**Looks like:** While a 3D/WebGL model streams in, a dim near-black silhouette of the model itself (not a generic spinner) sits centered, with a thin bar + "LOADING ASSETS" label beneath.
**Fits:** Any future maxfolio 3D-on-scroll hero (per the brief) — use the low-poly/placeholder mesh as its own loader.
**Sketch:** react-three-fiber `<Suspense fallback={<GhostMesh/>}>`; GhostMesh is the same geometry at 5% opacity, no textures.
**Perf/a11y:** Cheap since it reuses geometry already being fetched; add a text fallback for no-WebGL.
**Ref:** `refs4/awwwards-portfolio-b/usavionix-com/vp-0.png`

## 3. Avoid list

- **Fabricated stats/scarcity.** Idea 10's "spots filled" bar and any counter (idea 1's loader %, idea 30's numeral) must map to a real number Max can defend — never a decorative fake metric. Matches the house rule against invented ratings/placeholders.
- **Preloaders that gate real content for cosmetic reasons.** Forms.world and medhatalkadri.com's loaders visibly stalled in a plain headless capture — a percentage counter that doesn't reliably reach 100% (or blocks interaction while decorative) is a liability, not a feature. Any splash/boot sequence (idea 15) needs a skip control and a hard timeout fallback.
- **WebGL/canvas hero with no non-WebGL fallback.** Several sites here (hirotos.com, jordigarreta.com, schemeengine's dependency on video, jcedrik.com) rendered mostly blank in a standard browser context — if a scroll/3D hero can silently fail to paint, it needs a static-image or CSS fallback path, not just a "hope WebGL works" bet.
- **Autoplaying background video/audio without a mute-first default and reduced-motion path.** why.zero.university and schemeengine.com's full-bleed video heroes must stay muted-by-default and pause under `prefers-reduced-motion`; to-portfolio.com's exposed audio toggle is the right pattern (opt-in, visible) — don't default sound to on anywhere.
- **Gimmick chrome that breaks basic navigation.** Areeb Ali's POWER/STANDBY console cosplay and ZUI_OS's terminal cosplay are strong ideas only if the "off"/boot state never actually removes the page from keyboard/screen-reader reach — treat the skin as decorative CSS, not a real gate.
- **Inventing global/company signals that aren't true.** SLY's world-clock strip and Partizan's region tabs work because they're (presumably) true of those studios; a solo/small-agency portfolio using the same device to imply a bigger footprint than reality would be misleading — if reused, tie it to real facts (real client geography, real time zone) per the payment/claims-honesty house rule.
- **Long pages with no scroll progress cue.** unitedcarriers.com and stoneinvestment.fr run very tall with no scroll-position indicator; if maxfolio adopts a similarly long single-scroll narrative for a theme, pair it with a slim progress rail so users aren't lost.
- **Category tags as icon-only or image-baked text.** Keep hashtag tags (idea 13) and coordinate/timeline captions (ideas 16, 19, 23, 29) as real selectable/searchable text, never flattened into an image — several of the sampled sites bake small metadata into canvas/SVG in ways that are invisible to text search and screen readers.
