## 3. Avoid list

- **Vanity/inflated numbers** — never show a stat ("500+ projects", "10x conversion") that isn't independently verifiable from real data; the house rule against inventing ratings/claims applies to a personal portfolio too. If a real number is small or unglamorous, show it honestly or reframe the story instead of padding it.
- **Color-only chart encoding** — several inspiration pages (Awwwards impact/experience cards) leaned on color alone for state; always pair color with a label, icon, or text value.
- **Scroll-jacking / hard-locked scroll timelines** — the classic horizontal-train timeline pattern (rleonardi-style) can feel great but often fights the user's scroll wheel; if adopted, keep native scroll and only translate an inner element, never call `preventDefault()` on wheel/touch.
- **Decorative 3D that runs a permanent `requestAnimationFrame` loop** — kills battery/CPU and is exactly the kind of thing the house Lighthouse-measurement rule warns about ("Lighthouse measures MY CPU, not the site's" cuts both ways — a heavy idle 3D loop will tank real users' batteries too); always render on-demand or pause off-screen.
- **AnimatePresence wrapping page-level content with `exit` on route change** — house memory already documents this leaving a panel blank; keep exit-transitions off any real navigation outlet, only use them for isolated widgets (chapter photo crossfades, tooltips).
- **Typewriter/char-reveal text with no reduced-motion fallback and no persistent DOM text** — accessibility and screen-reader double-announcement risk; always keep full text in the DOM and gate the animation behind `prefers-reduced-motion`.
- **GitHub-style heatmaps/skylines built from fabricated data** — must be sourced from real commit/deploy history; a fake contribution graph is a lie dressed as data.
- **Cookie-banner-cluttered, ad-heavy layouts (as seen wrapping the Awwwards inspiration cards themselves)** — those pages are a fine *source* for a pattern but the pattern's presentation is not; extract the section idea, not the surrounding chrome.
- **Overloading one hero with every effect from this catalog at once** — the strongest reference sites (Brittany Chiang, Philip Walton) each commit to 1–2 signature moves and let restraint do the work; pick 2–3 ideas per theme, not all 28.
- **3D/skyline visuals with no static/text fallback** — screen readers and low-power devices need a text summary or poster image, never a canvas-only stat.
