- **onepagelove.com** `/tag/portfolio` — renders only site-wide nav chrome (genre/style/platform links), no showcase entries, even after scroll+wait; `/genre/portfolio` behaved the same. Substituted with **minimal.gallery**.

## Catalog — reusable ideas (30)

1. **Spotlight bento grid** — hover/focus tile jumps to full saturation while every sibling desaturates + dims to ~40% opacity, ~250ms ease. Fits: Apple Clean or Soft UI work grid. Sketch: CSS `filter: grayscale(1) opacity(.4)` on siblings via `:has(:hover)`/JS class toggle; keep both states in the DOM so no layout shift. Perf: filter is GPU-cheap; a11y: mirror the hover state on `:focus-visible` so keyboard users get the same cue. Ref: `galleries/kenjpena-com/vp-0.png`.
2. **Floating pill dock nav** — a rounded, semi-opaque nav bar centered at the bottom of the viewport instead of a top bar. Fits: Arcade/Menu theme, or as a persistent scroll-companion on any theme. Sketch: `position:fixed; bottom:24px; left:50%; translateX(-50%)`, backdrop-filter blur, hide-on-scroll-down/show-on-scroll-up via a scroll-delta listener. Perf: throttle the scroll listener (rAF); a11y: keep it in normal tab order, don't trap focus. Ref: `galleries/kenjpena-com/`, `galleries/balky-studio/`.
3. **Sculptural hero + docked marquee ticker** — one huge monochrome 3D/photo asset with an oversized outline wordmark overlapping it, client/date list scrolling as a marquee pinned to the very bottom edge of the viewport. Fits: Luxury theme hero. Sketch: CSS `animation: marquee 40s linear infinite` on a duplicated flex row (`translateX(-50%)`), pause on hover/`prefers-reduced-motion`. Perf: transform-only animation; a11y: `aria-hidden` the duplicate, respect reduced-motion. Ref: `galleries/smorgasbord-studio/vp-0.png`.
4. **OS-desktop-metaphor navigation** — the whole page reads as a soft-UI "desktop": draggable letter/app icons, a macOS-style dock, a rotating circular-text badge. Fits: a dedicated 7th/8th "OS" experience, or Arcade's menu screen. Sketch: each icon is an absolutely-positioned draggable div (pointer events + `transform: translate()`, no reflow); badge rotation via `@property --angle` + CSS `@keyframes`. Perf: drag via transform only; a11y: provide a plain-list fallback nav for screen readers (`sr-only` list mirroring the icons). Ref: `galleries/patrickmason-studio/vp-0.png`.
5. **Full-bleed photo + oversized hand-script logotype overlay** — a documentary-style photo hero with a giant white script wordmark centered on top. Fits: any media-heavy hero (Luxury, Apple Clean). Sketch: SVG or variable-font script overlay with `mix-blend-mode: difference` or plain white + `text-shadow` for legibility over varied photo tones. Perf: preload the hero image at the right `sizes`; a11y: wordmark is real text (not baked into the image) so it stays selectable/screen-reader-friendly. Ref: `galleries/careofchan-com/vp-0.png`.
6. **Neo-brutalist slab headline + capsule scroll cue** — huge black condensed type, a small pill-shaped "SCROLL" indicator with a dot that travels top-to-bottom inside it. Fits: Brutalist theme hero. Sketch: capsule is a fixed-height rounded div; dot animates via CSS `@keyframes translateY` looping with `animation-timing-function: ease-in-out`. Perf: trivial; a11y: `aria-hidden`, it's decorative. Ref: `galleries/balky-studio/vp-0.png`.
7. **Split-screen bio/case layout** — left column: name, contact, services, clients as plain stacked text; right column: one large realistic product/ad mockup photo. Fits: Apple Clean about/work split. Sketch: CSS grid `grid-template-columns: 1fr 1fr` collapsing to stacked on mobile; mockup image gets a subtle parallax `translateY` tied to scroll. Perf: parallax via `will-change: transform` + rAF-throttled scroll handler; a11y: ensure column order in DOM matches reading order (text before image) for screen readers. Ref: `galleries/clairouxstudio-com/vp-0.png`.
8. **Maximalist collage hero** — dark canvas, one organic blob/ribbon SVG shape behind, several 3D-rendered props scattered and slightly rotated, hand-lettered sticker labels, wordmark letters individually kerned apart as if physically placed. Fits: a Maximalist variant or Arcade's "shelf of stuff" motif. Sketch: absolutely-position each prop image with independent `rotate()`/`translate()`, stagger their entrance with a spring (framer-motion `staggerChildren`). Perf: keep props as optimized WebP/AVIF, lazy-load below the fold; a11y: group as one `role="img"` with a text alternative describing the collage, individual stickers `aria-hidden`. Ref: `galleries/studioloop-com-br/vp-0.png`.
9. **Scramble-decode headline + live city clock** — hero text starts as shuffled/foreign-looking characters and resolves letter-by-letter into the real headline; a live local time + city name sits beside it. Fits: Brutalist or Arcade "terminal boot" moment. Sketch: classic scramble-text effect (swap each char through a random charset for N frames before locking, GSAP `ScrambleTextPlugin` or a small custom `setInterval`); clock via `Intl.DateTimeFormat` updated every second. Perf: cap the scramble to run once per page load, not on every scroll-into-view; a11y: set the final text immediately in the DOM and only animate a visual overlay, so screen readers never see garbled text. Ref: `galleries/art-yakushev-com/vp-0.png`.
10. **Pull-quote hero** — a single serif quote in place of a conventional headline+subhead. Fits: any theme wanting an editorial opener. Sketch: large serif blockquote, quotation marks as oversized decorative glyphs positioned absolute. Perf: none; a11y: real `<blockquote>` + `<cite>`. Ref: `galleries/olivergareis-com/`.
11. **Grain-texture ambient ground + language/sound toggle pair** — a subtle animated film-grain noise layer over a flat background, with two small text toggles (language, sound) top-right. Fits: any theme wanting texture without a photo. Sketch: grain via a tiled SVG `feTurbulence` filter or a looping noise PNG at low opacity with `animation` on `background-position`; toggles are simple ARIA `switch` role buttons persisting to `localStorage`. Perf: SVG turbulence can be GPU-heavy — prefer a static tiled noise texture with a subtle CSS opacity pulse instead of true per-frame regeneration. Ref: `galleries/seunghyuk-com/vp-35.png`.
12. **Run-on-word stunt headline** — the hero sentence is typeset with zero spaces, daring the reader to parse it, breaking the "always readable" rule on purpose for a personality beat. Fits: a personal/terminal-styled about page. Sketch: pure typography, no special code — the trick is confidence, not tech. Ref: `galleries/leanrada-com/notes.txt` ("Welcometomypersonalwebsite!").
13. **Live CSS flow-field generative background** — a particle/flow-field animation driven by pure CSS (documented technique: `linear()` easing abuse) rather than canvas/WebGL. Fits: a lightweight "generative" hero for the dev-leaning theme. Sketch: animate many small elements along CSS `offset-path` curves with staggered `animation-delay`, using `linear()` timing functions to fake physics without JS. Perf: cap element count (~40-60), use `will-change: transform` sparingly; a11y: `prefers-reduced-motion` freezes the field. Ref: `galleries/leanrada-com/notes.txt`.
14. **Glossy liquid-chrome 3D bust + awards-count stat strip** — a soft, chrome-like humanoid 3D render as the hero focal point, with a row of award-body icons each showing a small number (wins/nominations). Fits: 3D/immersive theme hero. Sketch: pre-rendered WebM/GLB loop or a lightweight `<model-viewer>`; stat row is a plain flex row of icon+number pairs, counting up on scroll-into-view via a simple rAF tween. Perf: prefer a compressed looping video over live WebGL for a static-feeling asset; a11y: number counters get `aria-live="off"` with the final value present in the DOM immediately (no reliance on the animation). Ref: `galleries/redcollar-co/vp-0.png`.
15. **Sound-gate intro screen** — before the real homepage loads, show two buttons: "Enter with audio" / "Enter without audio" on a soft gradient ground. Fits: any theme that uses ambient audio. Sketch: a full-screen overlay component gating `<AnimatePresence>`; only starts `<audio>` playback after the explicit "with audio" click (never autoplay). Perf: preload the homepage bundle behind the gate while the user decides; a11y: default focus on the gate buttons, Escape/without-audio always available, never audio-only content. Ref: `galleries/emotion-agency-com/vp-0.png`.
16. **AI chat widget as the entire contact form** — replace a traditional "name/email/message" form with a single chat input inviting a free-form question. Fits: a "book a call" or contact section on a more product-y variant of the site. Sketch: a chat bubble UI backed by a lightweight LLM endpoint (or a scripted FAQ if no backend); log the transcript to email/CRM instead of a form POST. Perf: lazy-load the chat widget bundle on interaction, not on page load; a11y: full keyboard operability, `aria-live="polite"` region for new messages. Ref: `galleries/designerpart-com/notes.txt`.
17. **3D-hero with an honest static fallback** — a WebGL centerpiece that, when the device can't run it, swaps to a labeled still image ("This is a still of the interactive wall...") rather than a blank canvas or a spinner that never resolves. Fits: any theme with a WebGL hero (Arcade, 3D). Sketch: feature-detect WebGL2 support + a rough GPU/memory heuristic before mounting the 3D canvas; render an `<img>` of a pre-baked frame otherwise, with a one-line caption. Perf: this *is* the perf pattern — never force low-power devices to pay for a 3D scene they can't run; a11y: the fallback image needs real alt text describing what the interactive version shows. Ref: `galleries/kuarktek-digital/notes.txt`.
18. **Playfully-named product/skill cards** — instead of generic "UI Component" labels, ship cards with a persona-ish nickname ("A comfy icon → Discover Bulge") that doubles as a case-study entry point. Fits: a skills/capabilities section on any theme. Sketch: plain card grid, just a copy decision — each card = { tagline, nickname, cta }. Ref: `galleries/mariavareva-com/notes.txt`.
19. **Dev-tool ruler/pixel-grid as decorative chrome** — faux design-tool ruler ticks ("0, 100, 200…") along the top and left edges, plus a literal "1440px × 900px" label, used purely as art direction (not a real inspector). Fits: a portfolio for a design-engineer persona (leans into the "I build pixel-perfect things" identity). Sketch: absolutely-positioned SVG/CSS ruler with tick marks every N px, `pointer-events: none`; the "1440×900" label is static text, optionally swapped live via a `resize` listener for a knowing wink. Perf: pure decorative markup, negligible cost; a11y: `aria-hidden="true"` on the whole ruler layer. Ref: `galleries/corentinbernadou-com/vp-0.png`.
20. **Rotating 3D photo-textured cube as a hero prop** — a small Rubik's-cube-like object where each face is a case-study thumbnail, slowly auto-rotating, sitting beside the headline (not a full-screen 3D scene). Fits: Arcade or 3D theme, as a lightweight 3D accent rather than a heavy scene. Sketch: `react-three-fiber` `<mesh>` with 6 `<meshBasicMaterial map={texture}>` faces, `useFrame` incrementing rotation by a tiny delta each frame; pause rotation on hover to let users read a face. Perf: this is cheap 3D (one mesh, 6 textures) — safe even on modest GPUs; respect reduced-motion by freezing rotation. Ref: `galleries/corentinbernadou-com/vp-0.png`.
21. **Diagonal repeating masthead ticker** — a tall column of repeating project-name text running down one edge of the viewport, evenly spaced, like a magazine spine or running header. Fits: editorial/magazine theme side rail. ## Avoid list

- **CAPTCHA/bot walls on a portfolio's own homepage** (land-book.com's Cloudflare Turnstile) — actively hostile to crawlers, search indexing, and anyone sharing the link cold; a portfolio's entire purpose is to be seen.
- **Dead/misconfigured domains left linked from galleries** (evantolleson.com → "Site Not Found") — a stale DNS/hosting pointer erases the whole portfolio for any visitor who follows the link months later. Verify custom domains stay pointed after a host migration.
- **Cookie-consent modals that block the entire first viewport with no visible content behind them** (remedyeditorial.com) — the visitor's very first impression becomes a legal disclosure, not the work. Keep consent banners to an unobtrusive bottom strip.
- **Invalid SSL certificates on a live portfolio domain** (thisiswahba.com — `NET::ERR_CERT_COMMON_NAME_INVALID`) — the visitor sees Chrome's own red warning page instead of any design at all. Renew/verify certs on every custom domain before sharing a link.
- **Trusting a gallery's own category tag at face value** (moderncraftaz.com tagged "portfolio" on awwwards, actually a multi-location home-renovation business) — always verify what a linked site actually is before citing it as a style reference for a *specific* claim (here: "portfolio patterns").
- **Autoplaying audio without an explicit opt-in** — emotion-agency.com does this right (an explicit gate), which is the point: never skip the gate and autoplay.
- **A `scrollHeight` wildly disproportionate to the visible page** (clairouxstudio-com reported ~90,000px of scroll height against a visually short single-viewport-ish layout) — almost always a stray off-screen element (a mis-positioned absolute child, a hidden infinite-scroll sentinel) inflating the document; audit `document.documentElement.scrollHeight` during QA, not just what's visible on load.
- **Client-side-routed gallery feeds with no real `<a href>` on cards** (godly.website) — great for the gallery's own SPA, terrible for anyone (or any scraper/screen reader) trying to get a direct link to one entry; keep real anchor hrefs under interactive cards even when a JS router intercepts the click.
