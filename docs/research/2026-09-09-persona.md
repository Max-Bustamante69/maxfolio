## 2. Idea catalog (≥20, concrete + implementable)

Each idea names what it evokes, precisely what it looks like, where it could live in maxfolio, a
build sketch, and perf/a11y notes. None trace a game screenshot — shapes, palettes and type are
built from scratch using the *pattern*, not the *asset*.

### Color & material system

1. **Two-key-color law (P3 vs P5 doctrine).** What it looks like: exactly one saturated hero color
   (ice-blue for the calmer identity, or ink-red for the aggressive one) against near-black and
   near-white, with **zero mid-tone sub-colors** diluting it — confirmed directly by source #4 and
   #16 (P5 "hardly adopted sub-colors"; P3 used a single "moonlight yellow" sparingly as the only
   accent). Maxfolio section: whole `/persona` theme's token set. Sketch: two CSS custom properties
   only — `--p-ink` (near-black, not pure #000) and `--p-accent` (one saturated hue) — every other
   color is a tint/shade of those two via `color-mix()`. Perf: zero cost. A11y: verify the accent
   against `--p-ink` and against white both hit 4.5:1 for body text; reserve full-saturation accent
   for large type/decoration only.
2. **"Moon-water" gradient glass (P3R identity).** What it looks like per source #7 (Kumagai
   interview) and #8 (Kowalik's shader breakdown): a desaturated background, posterized into flat
   color bands, tinted cyan/teal, then given a slow vertical sine-wave UV distortion — "shimmer and
   reflection like glass." Maxfolio section: hero background or the case-study sheet backdrop on
   this theme. Sketch: CSS-only approximation — an `<img>`/gradient background under a
   `backdrop-filter: blur()` layer, animated with a `background-position` keyframe on a repeating
   diagonal-stripe gradient (`repeating-linear-gradient`) at low opacity, `mix-blend-mode: overlay`;
   no WebGL/shader needed for a portfolio budget. Perf: pure CSS, GPU-composited, cheap. A11y:
   respect `prefers-reduced-motion` — freeze the gradient position.
3. **Halftone dot field as a section-transition wash.** What it looks like: a comic-print halftone
   dot gradient (visible faintly in source #9's collage backgrounds and #16's CEDEC slide photos)
   used as a full-bleed texture behind a section break. Sketch: an inline SVG `<pattern>` of small
   circles at varying radius mapped along a gradient (radius via `feComponentTransfer` or a simple
   repeating radial-gradient trick), `opacity: .08–.15`. Perf: SVG pattern is cheap and resolution-
   independent — beats a raster halftone PNG. A11y: decorative, `aria-hidden`.
4. **Deep-Hour tint mode (P3's "Dark Hour").** What it looks like: source #13/#14 use a shift into
   near-black-navy with a thin red crack/particle overlay to signal a special mode. Maxfolio
   section: could gate the theme's own dark variant, or be the visual language for an "easter egg"
   / hidden state (e.g. a console-triggered mode) rather than default UI. Sketch: a CSS class that
   swaps `--p-ink` to a deeper blue-black and drops in a few `::before` radial "particle" dots
   animated with `translateY` drift. Perf: 4–6 pseudo-elements max, `will-change: transform`.

### Typography

5. **Condensed bold italic display type.** Google Fonts that genuinely evoke the look without being
   a licensed game font: **Anton** (ultra-bold condensed, great for oversized headline slabs —
   used similarly to source #14's "MEMENTO MORI"), **Archivo Black** / **Archivo Expanded** (heavy
   weight, good x-height for stacked headlines), **Teko** or **Rajdhani** (true condensed with a
   technical/HUD feel, good for labels and eyebrow text), **Bebas Neue** (classic poster-condensed
   fallback). For body/UI text pair with a clean grotesk already in the design system (avoid mixing
   more than 2 families). Apply `font-style: oblique 8deg` (real italic glyphs aren't guaranteed at
   every weight) plus a slight `letter-spacing` squeeze for the "shouted headline" effect seen across
   sources #14 and #9's "SPACEPORT OF GREED" card title. A11y: confirm condensed weights stay ≥16px
   effective for body copy; only headline slabs go tight.
6. **Eyebrow-dash-label pattern.** What it looks like (source #14, "— THE SQUAD" above "S.E.E.S."):
   a short red dash + small-caps tracked label sitting above a big headline. Maxfolio section:
   every section intro on this theme reuses this exact eyebrow pattern instead of a plain label —
   consistent "menu chapter header" feel. Sketch: trivial CSS (`::before` dash + `text-transform:
   uppercase; letter-spacing: .2em`).

### Motifs (shapes, panels, cards)

7. **Diagonal cut-in panel with torn edge.** What it looks like across sources #9 and #16: a black
   or colored panel doesn't sit in a rectangle — its edge is a jagged diagonal cut, often layered
   2–3 deep like torn paper, with a photo/portrait bleeding past the cut. Maxfolio section: the
   Shopify case-study sheet's photo mount, or a project card's image frame. Sketch: `clip-path:
   polygon(...)` with an irregular jagged path (5–7 points, not a clean diagonal) stacked on 2 divs
   at different z-index/offset for the "torn layers" depth; the outer layer gets a 1–2px offset
   drop-shadow to read as a paper edge. Perf: `clip-path` is GPU-friendly; avoid recomputing on
   resize by using percentage points. A11y: purely decorative framing, real content stays in normal
   flow inside the clipped box.
8. **Skewed parallelogram button/chip.** What it looks like (source #14's "ENTER THE DARK HOUR"
   CTA): a rectangle with one slanted vertical edge, not a full skew — flag/blade shaped. Maxfolio
   section: primary CTAs on this theme (contact, "view case study"). Sketch: `clip-path:
   polygon(8% 0, 100% 0, 92% 100%, 0 100%)`; keep the label upright and centered (don't skew the
   text, only the container) — this is the detail most fan CSS gets wrong per source #11's approach
   of skewing the *background shape*, not the type.
9. **Hexagon / angled stat tile.** Evokes the "status card" framing seen in the P5R dashboard case
   study (#9) and the gameuidatabase HUD screenshots (#15) — angled corner-cut cards instead of
   plain rounded rectangles. Maxfolio section: the stat band (count-up numerals) reskinned for this
   theme — replace hairline rows with angled corner-cut tiles in a row, one accent-color diagonal
   stripe per tile. Sketch: `clip-path: polygon(0 0, 92% 0, 100% 24%, 100% 100%, 8% 100%, 0 76%)`
   per tile; numerals stay in a plain `<span>` so count-up JS is untouched.
10. **Cursor-following selector polygon (source #11's actual mechanism).** What it looks like: two
    skewed SVG polygons that snap/track toward the hovered nav item, exactly like a JRPG menu
    cursor. Maxfolio section: desktop-only nav or the Explore-themes switcher. Sketch: an SVG
    `<polygon>` positioned absolutely, animated via a spring (`framer-motion`'s `useSpring` on
    x/width) to the `getBoundingClientRect()` of the hovered link — the CodePen's own JS settings
    object (`animationSpeed`, edge padding) is a clean 1:1 translatable spec into a `useSpring`
    config. Perf: transform-only animation, no layout thrash. A11y: keyboard focus must trigger the
    same tracking (`:focus-visible`), and it must not be the *only* hover indicator — pair with an
    underline/color change for screen-magnifier and no-JS users.
11. **Ghost oversized wordmark watermark.** What it looks like (source #14 hero, "PERSONA3
    RELOAD" bleeding faintly behind the headline at ~8% opacity, oversized and partially off-canvas).
    Maxfolio section: hero of this theme — the site's own initials or "MAXFOLIO" oversized, low-
    opacity, behind the real headline. Sketch: `position: absolute`, `font-size: 22vw`, `opacity: .05`,
    `mix-blend-mode: overlay`, `user-select: none; aria-hidden="true"`.
12. **Thin ring/compass motif behind hero copy.** What it looks like (source #14): a faint full
    circle outline centered behind the hero text block, subtly evoking a UI reticle/clock without
    copying any specific glyph. Maxfolio section: hero, or the Process stepper's background.
    Sketch: one inline SVG `<circle>` with `stroke` only, `stroke-dasharray` for tick marks,
    rotated slowly (`120s` linear) — cheap ambient motion.
13. **Arcana-style eyebrow tag cards.** What it looks like (source #14's character grid: small-caps
    Arcana name — FOOL, LOVERS, MAGICIAN — above each character's real name). Maxfolio section:
    Skills ledger or Projects index — tag each entry with an invented one-word "class" label (e.g.
    a skill tagged "ARCHITECT" or a project tagged "FLAGSHIP") purely as a structural device, own
    vocabulary, not the game's actual Arcana names.
14. **Sticker/callout label strip.** What it looks like (source #9's dashboard: small black
    rectangle + white bold text label, e.g. "Shadow Weaknesses", pinned at an angle over a photo).
    Maxfolio section: gallery carousel captions, or annotating a case-study screenshot. Sketch: a
    small `<span>` with `transform: rotate(-3deg)`, solid `--p-ink` background, positioned via CSS
    Grid area over the image, not absolute pixel coordinates (so it reflows on resize).

### Motion vocabulary

15. **Snap-in with overshoot ("menu open" animation).** What it looks like per multiple YouTube
    titles (#22–24) and the Kumagai interview (#7: "I want it to be more ephemeral"): panels don't
    fade in, they slam in from off-screen and overshoot slightly before settling — classic JRPG
    menu-open feel. Sketch: `framer-motion` spring with `stiffness: 400–500, damping: 22–26` (a
    visible small overshoot, not gentle) on `x`/`scale`, staggered 40–60ms per panel via
    `staggerChildren`. Maxfolio section: the case-study sheet opening, or the mobile nav drawer on
    this theme. Perf: transform/opacity only. A11y: swap to a plain 150ms fade under
    `prefers-reduced-motion`.
16. **Staggered diagonal slice reveal.** What it looks like: content mask-reveals along a diagonal
    line rather than a vertical wipe — matches the "cut-in panel" motif in motion. Sketch: a
    `clip-path: polygon()` keyframed from a closed diagonal wedge to full-rect using
    `framer-motion`'s `clipPath` animatable value, triggered by `whileInView`. Maxfolio section:
    Years unit-chart blocks landing one-by-one, or Gallery carousel slide transitions.
17. **"Crash / Breakout" impact-frame vocabulary (source #16's own naming).** What it looks like:
    a hard single-frame flash/scale-punch on click, then settle — literally named by Atlus's own
    UI team as two motion primitives: "Crash" (collision — a sharp snap-together of two elements)
    and "Breakout" (impact — a burst/shatter outward). Maxfolio section: primary CTA press states.
    Sketch: "Crash" = two elements animate toward each other and stop with a 1-frame 1.05x
    overshoot; "Breakout" = on click, 4–6 small triangle/shard divs burst outward and fade
    (`opacity`+`translate`, no physics engine needed, hand-keyed offsets). Perf: keep shard count
    ≤8, remove from DOM on `animationend`.
18. **Letter-jitter text pop.** Evoked by the "pop-punk" P5 branding language (#16) and common in
    fan recreations: headline letters animate in with a tiny random per-letter delay/rotation jitter
    before settling flush, rather than a uniform fade. Sketch: split text into spans (a lightweight
    manual split, not a heavy library), each gets a `framer-motion` variant with a randomized
    `rotate: [±6deg → 0]` and 15–30ms stagger. Use sparingly (hero headline only) — this is a
    "florituras" ask from the owner, but should not run on every heading or it reads as noisy.
19. **Hover skew + color invert on nav/cards.** What it looks like: on hover, a card doesn't just
    lift — it skews 2–3° and inverts its accent/ink relationship (background becomes the accent
    color, text becomes ink), same high-contrast-swap logic as the two-key-color law. Sketch: CSS
    custom-property swap on `:hover` (`--card-bg` / `--card-fg` flip) plus `transform: skewX(-2deg)`
    with a fast (120ms) ease-out. A11y: skew must not affect hit-testing/click target size; keep it
    visual-only via `transform` (doesn't change layout box).
20. **Screen-wipe section transition (diagonal).** What it looks like: between major sections, a
    solid diagonal-edged panel sweeps across the viewport before revealing the next section — akin
    to a menu-to-menu transition. Maxfolio section: candidate for the transition between this
    theme's hero and stat band, used once (not per-section, to protect scroll performance). Sketch:
    a fixed full-viewport div with `clip-path` animated from a wedge covering the screen to
    off-screen, driven by Lenis scroll progress or an intersection trigger; must be capped to a
    single occurrence to avoid scroll-jank across a whole page.
21. **Calendar/day-clock chrome as a Years-section reskin.** What it looks like: P3's calendar/
    clock UI chrome (referenced across #7, #15) — a date/time readout styled as thin monospace-ish
    numerals inside a bracket frame. Maxfolio section: direct fit for the existing "Years" unit
    chart — reskin the year labels as a calendar-day chip (`[ 20XX ]` bracket style) instead of a
    plain numeral, reusing the existing one-block-per-project data structure untouched.
22. **Dialogue-box contact form.** What it looks like: JRPG dialogue boxes — a bottom-anchored or
    modal panel with a name-plate tab cut into the top-left corner and an angled "next" indicator.
    Maxfolio section: direct fit for the Contact section on this theme. Sketch: the panel is a
    rounded-rect with one small notch cut via `clip-path`, the store-URL input sits inside it, and
    the magnetic CTA becomes a small triangular "▷ advance" indicator that pulses — reuses the
    existing magnetic-CTA JS, only the shape/label changes.
23. **"Velvet Room"-style vertical list for the Projects index.** What it looks like: a sparse,
    high-contrast vertical list on a near-black ground, each row keyed by a single accent-colored
    numeral/rune-like glyph on the left (own invented glyph set, not the game's actual cards) —
    conceptually close to a tarot-card list without depicting any tarot art. Maxfolio section:
    Projects index or Shopify Work index reskinned for this theme. Sketch: CSS grid rows, left
    column is a 40×40 box with a simple geometric monogram (SVG, own design) unique per entry,
    hover reveals a thin horizontal rule sweeping in from the glyph.

## 3. Avoid list (what forums/critiques call out)

- **Style over usability.** Source #6's own headline ("Is Persona 5's UI a hit or a miss?") and the
  broader critical thread around P5 confirm a real, recurring critique: dense diagonal/angled chrome
  can hurt scanability and hit-target clarity at high information density. For maxfolio: reserve the
  loudest motifs (torn-panel cut-ins, skewed everything) for hero/section-break moments; keep dense
  content (the Shopify case-study charts, the Years chart, the Skills ledger) on a calmer grid with
  the *color and type* system carried through, not every panel skewed.
- **Sub-color dilution.** The interview sources (#4, #16) are explicit that P5's team *deliberately
  avoided* extra accent colors because it weakens the hero color's impact — the most common amateur-
  recreation mistake (per the CodePen/fan-site pattern) is reaching for 3–4 accent colors. Cap this
  theme at one hero accent plus ink/paper neutrals.
- **Cloudflare/anti-bot walls signal these UIs are heavily fan-reverse-engineered and litigated
  around IP.** Multiple Medium articles and CodePens sit behind bot-checks or have been pulled/
  reworked; treat any specific pixel values, exact hex codes, or logo/glyph shapes as off-limits —
  work from the *pattern* (angles, color doctrine, motion primitives) documented above, never from
  a traced screenshot.
- **Don't fake the "underwater shader" with a heavy WebGL cost on a portfolio site.** Kowalik's own
  case study (#8) is a full Unreal Engine 5 material graph — appropriate for a game, not for a
  Lighthouse-scored portfolio hero. Use the cheap CSS-gradient/blend-mode approximation (idea #2),
  not a real-time render-target shader.
- **Condensed-italic body text hurts readability.** Keep condensed/oblique type to headlines and
  short labels only (per idea #5); never set paragraph copy in a squeezed condensed face.
- **Don't literally reuse Arcana names, character names, "SEES", "Phantom Thieves", or the games'
  actual taglines/logos.** Ideas #6, #13, #21 above are written to use invented equivalents
  (own class labels, own bracket-calendar chrome, own eyebrow copy) — this is a hard legal/ethical
  line, not just a style note.

## 4. THEME SPEC — "Persona"-evoking theme for maxfolio

### Color system
- **Two variants, pick one as default for the theme, keep the other as a possible easter-egg mode
  per idea #4:**
  - *Ice variant (P3-evoking):* `--p-ink: #0a0f1a` (near-black navy, not pure black), `--p-paper:
    #eef3f7` (cool off-white), `--p-accent: #3fa9dc`→`#1c6fb0` gradient range (ice-blue, own hex
    choice — do not sample the game's exact blue). One muted secondary only for small accents:
    a pale gold/"moonlight" `#c9a86a` used at <10% of UI surface, echoing the P3 sub-color doctrine
    without copying it.
  - *Ink variant (P5-evoking):* `--p-ink: #111013`, `--p-paper: #f5f2ee` (warm off-white/paper, not
    pure white — reads more "print" than "screen"), `--p-accent: #c8102e`→`#8f0b1f` (own red range).
    No secondary accent at all, per the sub-color-avoidance doctrine (idea #1/#4 in avoid list).
- Both variants: accent used for ≤15% of any viewport (headlines, CTAs, dashes, tile edges); ink and
  paper carry everything else. Verify accent-on-paper and paper-on-ink both clear WCAG AA for the
  text sizes actually used.

### Typography
- Display: **Anton** or **Archivo Black** (Google Fonts, confirmed free/open, no licensing risk) for
  oversized headline slabs — stacked two-line treatment like idea #5, one line ink-colored, one
  line accent-colored.
- Condensed label/UI face: **Teko** or **Rajdhani** (Google Fonts) for eyebrow labels, nav, stat
  tile numerals, calendar-chip numerals — tracked uppercase, small size only.
- Body: keep the portfolio's existing system-font body stack for actual paragraph copy — this theme
  changes headline/label typography and motifs, not readability-critical body text.

### Motifs (see catalog above for build sketches)
- Diagonal torn cut-in panels (idea #7) for photo/case-study mounts.
- Skewed parallelogram buttons (idea #8), angled corner-cut stat tiles (idea #9).
- Halftone dot wash (idea #3) as a section-break texture, used sparingly (1–2 places per page).
- Ghost oversized wordmark watermark (idea #11) + thin rotating ring motif (idea #12) in the hero.
- Own-glyph Arcana-style tags (idea #13) on Skills/Projects entries.
- Sticker callout labels (idea #14) on gallery captions.

### Motion vocabulary
- Snap-in-with-overshoot (idea #15) for panel entrances — spring, not ease curves.
- Staggered diagonal slice reveal (idea #16) for the Years blocks landing in view.
- "Crash / Breakout" click primitives (idea #17) for primary buttons.
- Letter-jitter headline pop (idea #18) — hero only, once per page.
- Hover skew + color-invert (idea #19) on nav links and index-row hovers.
- One diagonal screen-wipe (idea #20) between hero and stat band — the single "big" transition
  moment, not repeated per section (protects scroll perf and avoids the "style over usability"
  critique).

### Section-by-section mapping for maxfolio
- **Hero → "menu screen."** Ghost wordmark watermark + ring motif behind a two-line stacked
  headline (ink/accent split like source #14's "MEMENTO MORI"), eyebrow dash label above it, one
  skewed-parallelogram primary CTA + one plain-underline secondary link (mirrors #14's CTA pair
  exactly in structure, not literally).
- **Stat band → "status cards."** Angled corner-cut tiles (idea #9) in a row, count-up numerals
  unchanged, each tile edge in the accent color.
- **Now/marquee → keep the ticker, reskin the pill.** Small skewed pill chip, hover triggers the
  cursor-tracking selector polygon (idea #10) if the ticker items are interactive/linkable.
- **Experience → tabbed dialogue-style panel.** Role rail becomes a vertical list of own-glyph tags
  (idea #13's mechanism); the detail panel gets the torn-cut-in frame (idea #7) around any embedded
  screenshot/logo.
- **Years → "calendar."** Reuse idea #21 directly: bracket-style `[ 20XX ]` calendar-chip year
  labels on the existing one-block-per-project chart; no structural rebuild needed.
- **Process stepper → keep the self-drawing line, add the ring motif (idea #12) as ambient
  background**, each step's number set in the condensed UI face inside a small hex/angled badge.
- **Shopify Work index → "Velvet Room" list (idea #23).** Sparse near-black vertical list, own
  monogram glyphs, torn-cut-in preview thumbnail on hover.
- **Case-study sheet → the moon-water glass background (idea #2)** behind the header, chart cards
  as angled-corner tiles (idea #9), sticker callout labels (idea #14) annotating key numbers.
- **Gallery carousel → diagonal slice transition (idea #16)** between slides instead of a plain
  slide/fade; sticker captions (idea #14) pinned over each frame.
- **Manifesto inverted band → the "Crash" primitive (idea #17)** on entry: the band's two color
  halves (ink/accent) snap together from opposite edges.

### Parallax layers plan
1. **Back layer (fixed/slow):** ghost wordmark + ring motif + halftone wash — `translateY` at ~0.2×
   scroll speed via Lenis, or `background-attachment`-style CSS approximation.
2. **Mid layer (section content):** normal scroll speed, all real content and cards.
3. **Front layer (fast, sparse):** a handful of small accent shards/particles (idea #17's leftover
   shard shapes reused as ambient decoration) at ~1.15× scroll speed, capped to 6–10 elements total
   across the page to protect performance — not a per-section effect.
- Implementation: Lenis already drives smooth scroll; wire parallax layers through Lenis's scroll
  callback updating CSS custom properties (`--scroll-y`) consumed by `transform: translateY(calc(...))`
  rather than JS-driven inline styles per frame, to stay off the main thread as much as possible.
  Respect `prefers-reduced-motion`: disable all three layers' motion, keep static positions.
