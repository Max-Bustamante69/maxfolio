# LENS: effects — clean, high-taste interaction catalog for maxfolio.dev

Scope: catalogs of small, reusable interaction effects (not full page layouts) — text, cursor, hover, background, number, border, marquee, morph, header, transition, trail — scored for an Apple-clean baseline, with a framer-motion/CSS/Lenis implementation sketch that adds **zero new dependencies** beyond what maxfolio already has (React 19, Tailwind 3, framer-motion via LazyMotion, Lenis).

Capture method: Playwright/Chromium 1440×900 (some 390×844 spot checks), `domcontentloaded` + 1.6s settle, polite ≥2s/host spacing. Screenshots at `…/scratchpad/refs3/effects/`. Two capture passes landed in the same cache dir (this session's `refs3-effects.mjs` + an earlier partial attempt already sitting there) — both are folded into the table below since neither repeats a site the two `2026-09-lenses-workflow-*.md` digests already covered.

## 2. Effect catalog (34 entries)

Legend: **Taste** = 1–5, Apple-clean bias (5 = restrained/premium, 1 = gimmicky/dated). **Section** = best-fit maxfolio route/section. **Screenshot** = file in `refs3/effects/` (omitted where the idea is a synthesis of an article, not a single screenshot).

### Text

**1. Split-text line-mask reveal** — Taste 5
Each line of a heading sits in an `overflow:hidden` wrapper; the line itself translates up from `y:110%` to `y:0%` with a slight stagger (60–90ms) per line, `duration 0.6s`, `ease [0.22,1,0.36,1]` (Motion's "expo-out" custom bezier — matches Josh Comeau's guidance that entrance eases should decelerate hard). Trigger: `whileInView` with `margin: "-10% 0px"`.
Section: hero headline, Manifesto band, section eyebrows.
Implementation: wrap each line in `<span className="block overflow-hidden"><motion.span variants={line}>…</motion.span></span>`; split by `\n` at build time (no runtime text-measurement library needed since copy is authored, not dynamic).
Perf/a11y: transform-only (no layout thrash); respect `prefers-reduced-motion` by collapsing to opacity-only fade.
Screenshot: `aceternity-components-ui-aceternity-com-blocks-text-animations.png` (catalog page).

**2. Text scramble-in** — Taste 4
Characters cycle through a random glyph set (uppercase letters + a few symbols) for ~400ms then lock to the real character, left-to-right with a 15–20ms stagger per character.
Section: Now-pill status text, marquee ticker items on hover, Skills ledger tag reveal.
Implementation: a small `useScramble(text, {duration, charset})` hook using `setInterval`/`requestAnimationFrame`, no library — same primitive as Animata's Gibberish Text.
Perf/a11y: cap to short strings (<20 chars) to avoid layout jitter; announce final text via `aria-live="polite"` only once, not per-frame.
Screenshot: `animata-animata-design-docs-text-gibberish-text.png`.

**3. Typewriter caret reveal** — Taste 3
Characters appear one at a time with a blinking `|` caret; ~35–45ms/char.
Section: Contact CTA line or a single punchy manifesto sentence — overuse elsewhere reads dated.
Implementation: CSS `steps()` animation on a `ch`-unit width, or framer-motion `animate` over string length.
Perf/a11y: skip on reduced motion (show full text instantly); don't use for long paragraphs (fatigue).
Screenshot: `animata-animata-design-docs-text-typing-text.png`.

**4. Number ticker (count-up on hairlines)** — Taste 5 — *already in maxfolio's stat band; upgrade candidate*
Digits count from 0 (or previous value) to target over 1.2–1.6s with an ease-out cubic, optionally with odometer-style vertical digit-roll instead of a flat count.
Section: stat band, case-study sheet charts, "18 storefronts" dense-info tile.
Implementation: `useSpring`/`useMotionValue` bound to a `<motion.span>` that formats via `useTransform(v => Math.round(v).toLocaleString())`; trigger on `whileInView` once.
Perf/a11y: throttle to `requestAnimationFrame`, never `setInterval`; expose the final static number in a visually-hidden node for screen readers so mid-animation values aren't announced.

### Cursor & hover

**5. Spotlight/cursor-gradient card** — Taste 5
A `radial-gradient` mask follows the pointer inside a card border, fading to transparent ~200px out; updates via CSS custom properties (`--x`, `--y`) set on `pointermove`, not React state, so there's zero re-render cost.
Section: Shopify Work index cards, Skills ledger rows, case-study sheet nav.
Implementation: `el.style.setProperty('--x', x+'px')` in a raw event listener (bypass React); `background: radial-gradient(200px circle at var(--x) var(--y), rgba(255,255,255,.08), transparent 70%)`.
Perf/a11y: desktop-only (`@media (hover:hover)`); no-op on touch.
Screenshot: `aceternity-ui-aceternity-com-blocks-bento-grids.png` (bento cards with ambient glow).

**6. Magnetic element** — Taste 4
Button/CTA offsets toward the cursor within a ~40–60px capture radius, max displacement ~12px, spring `{stiffness: 150, damping: 15}`; snaps back on leave.
Section: Contact magnetic CTA (already planned) — extend to nav links and the theme-switcher pills.
Implementation: framer-motion `useMotionValue` x/y driven by `pointermove` distance-from-center, wrapped in `useSpring`.
Perf/a11y: cap max displacement so focus-ring position doesn't visually detach from the real hit target; keep keyboard-focus state static (no magnet effect on `:focus-visible`).

**7. 3D tilt + glare card** — Taste 4 (5 if glare is subtle)
Card rotates on X/Y (±6–8°) following cursor position within its bounds, `perspective: 1000px`, plus a soft specular highlight (radial-gradient overlay) that moves opposite the tilt.
Section: Shopify Work case-study cards, Gallery laptop/phone frames.
Implementation: framer-motion `rotateX/rotateY` via `useTransform` of pointer position normalized to card bounds; glare as an absolutely-positioned pseudo-layer with `mix-blend-mode: overlay`.
Perf/a11y: `will-change: transform` only while hovered (remove after, to avoid idle compositing cost); disable entirely on touch (no hover) and under reduced-motion.
Screenshot: (component confirmed live at) `aceternity :: 3D Card Effect` — https://ui.aceternity.com/components/3d-card-effect.

**8. Smooth-lag custom cursor** — Taste 4, high risk of feeling gimmicky — use narrowly
A small dot/ring replaces the OS cursor and trails the real pointer with a spring lag (`stiffness ~300, damping ~30`), scaling up over interactive elements.
Section: desktop-only, maybe just within the Gallery carousel or Years unit-chart (signals "this area is special").
Implementation: single fixed-position `motion.div`, `pointer-events:none`, position via `useSpring(mouseX/mouseY)`; swap `cursor:none` only inside the wrapping section, not globally.
Perf/a11y: never remove the native cursor site-wide (breaks usability expectations); always provide a fallback on touch/reduced-motion.

**9. Image reveal via clip-path on hover** — Taste 5
Thumbnail sits under a solid color panel; on hover the panel's `clip-path: inset()` animates from `0% 0% 0% 0%` (fully covering) to `100% 0% 0% 0%` (fully revealed) over ~500ms, diagonal or directional per design.
Section: Projects index thumbnails, Gallery carousel captions.
Implementation: pure CSS custom property + Tailwind arbitrary value, or framer-motion `clipPath` string interpolation.
Perf/a11y: `clip-path` is compositor-friendly (no layout), safe for many instances on one page.

**10. Cursor trail (cheap CSS version)** — Taste 3, novelty — use once, if at all
3–5 small dots/blurred circles follow the pointer with staggered spring delays (each ~30ms behind the previous), fading in opacity along the tail.
Section: candidate only for the Persona-3 game-UI theme's hero (fits the "comic energy trail" mood) — wrong tone for Apple Clean.
Implementation: array of `motion.div`s each with its own `useSpring(mouseX, {stiffness: 200-i*20, damping: 20})`; skip WebGL fluid sims like React Bits' Splash Cursor entirely.
Perf/a11y: hard-disable on touch and reduced-motion; cap trail length to 5 nodes.

### Backgrounds

**11. Dot-grid with proximity glow + click shockwave** — Taste 4 (dial opacity down for Apple-clean)
Static dot grid; dots within ~150px of the cursor brighten/scale, and a click sends a radial "shockwave" that displaces nearby dots outward then springs them back (`resistance ~750`, `returnDuration ~1.5s` per React Bits' own defaults).
Section: hero background (very subtle, low-opacity) or footer/Explore-themes background.
Implementation: **do not** pull in GSAP (React Bits' actual dependency) — reimplement with a `<canvas>` or a grid of absolutely-positioned divs driven by framer-motion springs on pointer distance; cap grid density adaptively by viewport width.
Perf/a11y: canvas approach scales far better than N `motion.div`s once dot count exceeds ~200; always keep contrast/opacity low enough not to fight foreground text (WCAG non-text contrast isn't at stake since it's decorative, but readability still matters).
Screenshot: `reactbits-backgrounds-full.png` (full prop table + live demo).

**12. Blurry drifting blob** — Taste 5 — cheapest ambient motion available
One or two large blurred gradient circles (`filter: blur(80–120px)`) slowly translate/scale over 15–25s loops, `ease: "easeInOut"`, `repeat: Infinity`, `repeatType: "mirror"`.
Section: section transition backgrounds (behind Manifesto band, behind Contact), very low opacity in light theme.
Implementation: two `motion.div`s with looping `animate={{x: [...], y: [...], scale: [...]}}`; pure transform, GPU-cheap.
Perf/a11y: no interaction needed, so no a11y concern; still respect reduced-motion (freeze at a mid-frame position).
Screenshot: `animata-animata-design-docs-background-blurry-blob.png`.

**13. Shape-grid background (rotate/morph on scroll)** — Taste 4
Grid of small geometric shapes (squares/triangles) that rotate or change opacity as a function of scroll progress, computed once via `IntersectionObserver`/`useScroll`, not per-shape listeners.
Section: alternative to #11 for a lighter, more geometric Apple-Clean backdrop behind the Years unit-chart.
Implementation: single `useScroll({target: sectionRef})` value mapped via `useTransform` to a CSS custom property applied to the whole grid container (`--rot`), read by each shape via `rotate: calc(var(--rot) * var(--factor))` — one JS binding, N CSS consumers.
Perf/a11y: this "one scroll listener, many CSS consumers" pattern avoids the classic N-listeners performance trap.

**14. Animated connector beam** — Taste 4
An SVG path between two DOM anchors (measured via `getBoundingClientRect`) with a traveling gradient-stroke "pulse" animated via `stroke-dashoffset` or an animated gradient `<linearGradient>` position.
Section: a "how a storefront connects to the Digitdeck platform/app" diagram inside a case-study sheet or the Process stepper.
Implementation: recompute path on resize (`ResizeObserver`), animate `stroke-dashoffset` with framer-motion; keep the path itself static (don't re-measure every frame).
Perf/a11y: provide the same info as a plain sentence in the DOM for screen readers (the diagram is decorative reinforcement, not the only channel).
Screenshot: `animata-animata-design-docs-background-animated-beam.png`.

### Borders, buttons, chrome

**15. Border beam** — Taste 5
A short gradient segment travels continuously around a container's border, `duration ~6s`, linear, infinite loop; color pair e.g. `#ffaa40 → #9c40ff` (Magic UI's shipped default — swap for maxfolio's palette), `borderWidth 1–1.5px`.
Section: active/selected state on the theme-switcher pills, the Now-pill's outer ring, a "featured" Shopify Work card.
Implementation: an absolutely-positioned pseudo-element the size of the border, `offset-path: rect(...)` or a `conic-gradient` masked to a 1px ring, animated via `background-position`/`offset-distance`.
Perf/a11y: one instance at a time is cheap; avoid running more than 2–3 simultaneously (compositor cost adds up) — use only for genuinely "active" elements, not decoration everywhere.
Screenshot: `magicui-buttons-full.png` (full prop table + live preview).

**16. Shimmer sweep (button/text)** — Taste 4
A diagonal light band sweeps across a button or headline once every 3–4s (or on hover only), via a `background: linear-gradient(110deg, transparent 40%, rgba(255,255,255,.5) 50%, transparent 60%)` animated on `background-position`.
Section: primary CTA idle-state hint, "Explore themes" pills.
Implementation: pure CSS `@keyframes`, no JS; gate the idle auto-loop behind `prefers-reduced-motion: no-preference`.
Perf/a11y: CSS-only = negligible cost; don't combine with border-beam on the same element (visual noise).

**17. Ripple on click/tap** — Taste 3, use sparingly (material-design association can feel "borrowed," not premium)
A circle scales from the click point to cover the element, opacity fading 0.4→0, ~500–600ms.
Section: only where a real state change happens (e.g., "copy store URL" confirmation) — never as pure decoration.
Implementation: framer-motion `AnimatePresence` mounting a short-lived absolutely-positioned circle at click coordinates.
Perf/a11y: keep under ~10 concurrent instances (rapid clicking); doesn't replace a real focus-visible outline.

**18. Morphing icon (hamburger ↔ close, plus ↔ minus)** — Taste 5
SVG path `d` attribute (or two stacked paths cross-faded) morphs between states over 250–300ms, `ease: [0.4,0,0.2,1]`.
Section: mobile nav toggle, accordion/FAQ expand affordance.
Implementation: framer-motion `<motion.path d={...}/>` with the `d` value itself as an animatable string (Motion supports path morphing directly when point counts match) or two overlaid `motion.line`s rotating into an ✕.
Perf/a11y: keep `aria-expanded`/`aria-label` in sync with the *logical* state, independent of animation progress.

**19. Sticky header that shrinks + gains a background** — Taste 5
Header height/padding and logo scale decrease (e.g., 96px → 64px) as `scrollY` passes a threshold (~80px), background goes from transparent to a blurred surface (`backdrop-filter: blur(12px)` + low-opacity fill), all scroll-linked not scroll-event-debounced.
Section: global nav — pairs naturally with Lenis since Lenis already emits a smooth `scroll` value to bind to.
Implementation: `useScroll` mapped via `useTransform` to height/opacity/blur custom properties; bind directly to Lenis' `scroll` event with `useMotionValue` rather than React state to avoid re-renders every frame.
Perf/a11y: transform/opacity/backdrop-filter only (no layout-triggering height animation on the *content* below it — animate a max-height wrapper, not the flow height, to avoid reflow-per-frame).

**20. Section-aware nav (active-link indicator that slides)** — Taste 5
An underline/pill slides between nav items to match the section currently in view, `spring {stiffness: 300, damping: 30}`, driven by `IntersectionObserver` per section.
Section: global nav, and internally within the case-study sheet's anchor-nav.
Implementation: framer-motion `layoutId="nav-indicator"` shared across the candidate links — layout animations handle the slide/resize automatically.
Perf/a11y: `IntersectionObserver` (not scroll-position math) for correctness on Lenis' virtual scroll; keep the *link itself* focusable/clickable independent of the indicator.

### Layout, list, and page-level

**21. Bento grid with per-cell hover lift** — Taste 5
Asymmetric grid (2×2, 1×2, etc.) of cards; hovered cell lifts (`y: -4px`, subtle `box-shadow` growth) while siblings dim slightly (`opacity: 0.85`), ~200ms.
Section: "18 storefronts / apps / products" dense-info section, tech-stack display.
Implementation: CSS grid with `grid-template-areas` per breakpoint (bento layouts should be hand-authored per breakpoint, not auto-flowed); hover state via Tailwind `group`/`group-hover`, no JS needed unless the dim-siblings behavior requires a shared hover context (`useState` on the grid parent).
Perf/a11y: ensure each cell remains independently focusable/keyboard-navigable (bento layouts often break DOM/visual order — verify tab order matches visual reading order).
Screenshot: `aceternity-ui-aceternity-com-blocks-bento-grids.png`, `magicui-docs-magicui-design-docs-components-bento-grid.png`.

**22. Marquee with edge-fade mask + hover-pause + direction-reverse row pairs** — Taste 5 — *direct upgrade for the existing Now-pill/marquee ticker*
Row of items scrolls infinitely (CSS `@keyframes translateX(-50%)` on a doubled children list, not JS-driven), masked to fade at both edges (`mask-image: linear-gradient(90deg, transparent, black 10%, black 90%, transparent)`), pauses on hover, alternating rows can reverse direction for a "woven" feel.
Section: Now/marquee band, client/stack logo strip.
Implementation: pure CSS animation (best perf — no JS per frame); `animation-play-state: paused` on `:hover`; duplicate the content array once so the 50%-translate loop is seamless.
Perf/a11y: `aria-hidden` the duplicated copy, keep one accessible list for screen readers; pause automatically when the tab is backgrounded (`document.visibilitychange`) as a courtesy, not strictly required.

**23. 3D/isometric marquee** — Taste 3, striking but heavy-handed — use once max
Same infinite-scroll marquee concept but each row is rotated in 3D space (`rotateX`/`rotateY`/`perspective`) so multiple rows form a receding isometric wall of cards.
Section: candidate only for the Persona-3 theme's Shopify Work index (fits the "cut-in panel" comic-diagonal mood) — wrong register for Apple Clean or neumorphism.
Implementation: CSS `transform-style: preserve-3d` on a shared perspective container, each row offset in Z.
Perf/a11y: heavier compositing (many 3D layers) — cap to ≤3 rows, ≤6 visible cards/row; disable on low-end/mobile via a viewport or `navigator.hardwareConcurrency` check.
Screenshot: `magicui-docs-magicui-design-docs-components-marquee.png` (3D example in that same doc page).

**24. Draggable reorder grid** — Taste 4, interactive-toy energy — good for one "playful" moment
Grid items can be dragged and reordered by the visitor; released items spring into their new grid position (`layout` animations), other items reflow with a spring.
Section: an interactive "rank what matters to you" skills widget, or letting a visitor reorder the Years unit-chart's kind-filter chips.
Implementation: framer-motion's `<Reorder.Group>`/`<Reorder.Item>` — already available since maxfolio ships framer-motion; this is the React equivalent of the Motion.dev Vue reorder-grid example.
Perf/a11y: drag interactions need an equivalent keyboard path (e.g., arrow-key reorder) — `Reorder.Item` doesn't give this for free, so pair with a visually-hidden "move up/down" button pair per item.

**25. Scroll-driven line/path draw** — Taste 5 — *direct upgrade for the existing Process self-drawing line*
An SVG path's `stroke-dashoffset` (or a Motion `pathLength` motion value) is bound directly to scroll progress through the section (0→1), not to a fixed duration — so the line's draw speed matches the visitor's own scroll speed.
Section: Process stepper (already conceptually there — this formalizes the binding).
Implementation: Motion's native `scroll()` helper (used verbatim in the motion.dev Three.js-logo example) bound to `pathLength`; with Lenis in play, drive it off Lenis' scroll value via `useMotionValue` + `useTransform`, not the native scroll event, so it stays in sync with the smoothed scroll.
Perf/a11y: purely presentational — keep the actual step content in normal document flow so screen readers/keyboard users get the real sequence regardless of the drawn line.

**26. View Transitions API for theme/route changes** — Taste 5 (Apple-native feel), progressive-enhancement required
Native `document.startViewTransition()` cross-fades/morphs the outgoing and incoming page states on navigation (e.g., switching between the four theme routes, or opening a case-study sheet), no manual animation code for the crossfade itself — the browser diffs old/new pixels.
Section: theme-switcher navigation (`/`, `/luxury`, `/brutalist`, `/menu`), case-study sheet open/close.
Implementation: wrap the route change in `document.startViewTransition(() => flushSync(() => navigate(...)))`; feature-detect (`if ('startViewTransition' in document)`) and fall back to the existing instant/CSS transition otherwise — zero new dependency, it's a browser API.
Perf/a11y: browser-native compositing (very cheap); respect reduced-motion by skipping the transition wrapper entirely (fall through to instant navigation) when the media query matches.

### Micro-interactions & philosophy (from Emil Kowalski / Josh Comeau)

**27. "Boop" micro-interaction** — Taste 5
A small icon/emoji rotates a few degrees and scales up briefly on hover/click, spring-driven so it feels tactile rather than linear, then relaxes back — deliberately tiny and quick.
Section: Now-pill's status dot, a skill-tag icon, the contact page's send button.
Implementation: framer-motion `whileHover={{rotate: 10, scale: 1.15}}` with a `type: "spring", stiffness: 300, damping: 10` transition — this is the exact recipe from Josh Comeau's article, already achievable with maxfolio's existing framer-motion setup.
Perf/a11y: trivial cost; keep the rotation small (≤15°) so it reads as playful, not broken.

**28. Distance-aware duration scaling** — Taste 5 (craft principle, not a single visual)
Animations that move an element further travel proportionally longer (not a fixed duration for every transform), so a modal sliding 400px doesn't feel as rushed as one sliding 40px at the same speed — Emil Kowalski's practical-tips piece names this explicitly as a common miss.
Section: apply as a rule across every slide/translate transition site-wide (drawer/sheet opens, case-study sheet, mobile nav).
Implementation: compute `duration = clamp(0.2, distance / velocityConstant, 0.6)` when defining transition props, rather than hardcoding one duration for all translate distances.
Perf/a11y: not itself a perf concern; improves perceived quality at no extra cost.

**29. Deliberate friction as a feature (restraint principle)** — Taste 5 (this *is* the taste move)
Kowalski's argument: removing all friction isn't always right — a small, honest pause or confirmation step can read as more trustworthy than instant, frictionless motion everywhere.
Section: apply to anything with real consequence in the portfolio's few interactive moments — e.g., the "copy store URL" or contact-form submit shouldn't be instant-and-silent; a brief, confident settle (150–250ms) before the success state reads more premium than a snap.
Implementation: not a code recipe — a review checklist item: "does every instant transition deserve to be instant, or does one beat of friction make it feel more considered?"
Perf/a11y: directly supports the "not everything needs `duration: 0.15s`" restraint that keeps a site from feeling twitchy — also the single best defense against over-animating when adding "more florituras."

### Cheap CSS-only micro-effects (Uiverse-sourced, zero JS)

**30. Gradient-border sweep button** — Taste 4
Button border is a `conic-gradient` masked to a thin ring; on hover the gradient's rotation angle animates via a CSS custom property (`@property --angle`) so the color sweeps around the border continuously.
Section: secondary CTAs, Explore-themes pills.
Implementation: `@property --angle {syntax:'<angle>'; inherits:false; initial-value:0deg}` + `@keyframes spin {to {--angle:360deg}}`; pure CSS, no framer-motion needed.
Perf/a11y: `@property`-driven custom-property animation is GPU-cheap and doesn't need JS at all; verify support fallback (static gradient) for older Safari.

**31. Glass-shine card hover** — Taste 4
A soft diagonal highlight band crosses a card once on hover (not looping), suggesting a glass/glossy surface — same mechanic as #16 but single-shot and tied to `:hover` rather than auto-looping.
Section: pricing-style comparison rows if maxfolio ever adds one, or the Skills usage ledger rows.
Implementation: pure CSS `background-position` transition on `:hover`, `transition: background-position .6s ease`.
Perf/a11y: CSS-only, negligible cost.

**32. Checkbox/toggle morph (Uiverse-style)** — Taste 3, niche fit
A toggle or checkbox animates its own shape (square→check, circle→pill) rather than just fading a checkmark in.
Section: only relevant if maxfolio adds a real settings control (e.g., a density/compact toggle on the Years chart) — otherwise skip, low relevance to a portfolio.
Implementation: two stacked SVG paths cross-faded + scaled, or a single morphing path if point-count-matched.
Perf/a11y: keep `role="switch"`/`aria-checked` in sync with the *state*, not the animation frame.

### Judgment calls / heavier reference-only ideas (log, don't ship as-is)

**33. Custom right-click context menu** — Taste 3, novelty
Replaces the OS right-click menu with a branded one offering shortcuts ("Copy site URL," "View source," "Switch theme").
Section: an Easter egg, desktop-only, never the primary interaction path.
Implementation: `contextmenu` event `preventDefault()` + a small positioned `motion.div` menu (cuicui's Context Menu is the reference, not the library itself).
Perf/a11y: must still allow the *real* browser context menu to work if the visitor needs it (e.g., via a modifier key) — don't fully trap it; also keyboard-operable (menu key / Shift+F10) if implemented at all.

**34. WebGPU/Three.js liquid-glass & particle-morph scenes** — Taste 5 visually, Taste 1 for this project's constraints
Codrops' liquid-glass grid and motion.dev's Three.js particle-morph examples represent the current high-end ceiling for "wow" — full-scene WebGL/WebGPU shaders reacting to scroll/cursor.
Section: none, directly — but the *mood* (refraction, soft glass, particle dissolve) can inform color/blur choices in cheaper 2D effects (e.g., a `backdrop-filter: blur()` "glass" panel behind the case-study sheet, instead of a real shader).
Implementation: do not implement literally — no new WebGL/Three.js dependency for a portfolio; borrow only the *visual reference* (soft refraction, subtle chromatic fringing via layered gradients) into CSS-only approximations.
Perf/a11y: this is exactly the class of effect the "zero new dependencies" and performance-pattern requirements rule out — flagged explicitly so it isn't reached for later without discussion.

## 3. Avoid list (what forums/award judges/these sources themselves flag as overdone or risky)

- **Splash/fluid-sim cursors and full WebGL particle fields** (React Bits' Splash Cursor, Magic UI's Floating 3D Particles, motion.dev's Three.js examples) — gorgeous in isolation, but add a real dependency (Three.js/WebGL/GSAP) maxfolio doesn't have, and tank Lighthouse/TBT on anything but a high-end GPU. Approximate the *mood* in CSS instead.
- **Custom cursor site-wide** — hiding the native cursor everywhere breaks a basic usability expectation and fails hard on touch/trackpad edge cases; scope any custom cursor to one clearly "special" section, never the whole site.
- **Webcam-driven effects** (Aceternity's Webcam Pixel Grid) — a portfolio asking for camera permission reads as a red flag before it reads as clever; skip entirely.
- **`transition: all`** — Josh Comeau's CSS-transitions piece calls this out directly: it silently animates properties you didn't intend (including ones that trigger layout), and makes performance regressions invisible. Always name the specific properties.
- **Ripple/checkbox-morph borrowed wholesale from Material Design** — reads as "borrowed system," not bespoke, when dropped into an otherwise Apple-clean or premium-editorial site; use only where it's the *most honest* signal for the interaction (a real tap confirmation), not as decoration.
- **Auto-looping shimmer/marquee-everywhere** — several of the catalogs (hover.dev, Magic UI) ship every component with a default auto-loop; stacking more than 2–3 simultaneously-animating loops on one viewport reads as restless rather than alive. Pick one "breathing" element per section, not one per card.
- **Text scramble/typewriter on long copy** — fine for a 2–5 word label, fatiguing and an accessibility annoyance (screen readers, patience) on a full sentence or paragraph; reserve for short, punchy strings only.
- **3D/isometric marquees and cut-in comic panels everywhere** — striking once, but if every section reaches for the same "wow" trick the site loses hierarchy; the Persona-3 and neumorphism themes should each have 1–2 signature moves, not the whole catalog.
- **Ignoring `prefers-reduced-motion`** — none of the source libraries default to respecting it in their demos (they're demo sites selling the effect); every one of the 34 catalog entries above needs an explicit reduced-motion fallback before shipping, since Awwwards/Codrops-adjacent sites are frequently criticized in their own comment sections for motion-sickness-inducing demos with no opt-out.
- **New runtime dependencies for a single effect** — GSAP (React Bits' Dot Grid), Three.js/WebGPU (Codrops, motion.dev 3D examples), and SVG-filter-heavy blob cursors all tempt a "just add the library" shortcut; the brief is explicit that maxfolio stays on framer-motion/CSS/Lenis only, so every idea above was checked against that constraint and re-sketched in-toolkit where the original used something heavier.
